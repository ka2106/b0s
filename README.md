# БОС · Аналитика

Одностраничный дашборд строительства складов: сводные KPI, реестр объектов, карта площадок
и сравнение двух выгрузок. Без сборки и зависимостей — только статические файлы.

## Быстрый старт

```powershell
git clone https://github.com/ka2106/b0s.git
cd b0s
npx serve -l 5173 .
```

Открыть <http://localhost:5173>. Ключ Яндекс.Карт вводится на вкладке «Карта» и запоминается в
браузере — в репозитории и в файлах его нет.

Подробная инструкция для нового устройства (с нуля: Git, Node.js, VS Code, доступ к GitHub):
[`docs/setup-new-device.html`](docs/setup-new-device.html) — открывается двойным кликом в браузере.

## Состав

| Файл         | Назначение                                                         |
| ------------ | ------------------------------------------------------------------ |
| `index.html` | разметка всех вкладок: Дашборд, Таблица, Карта, Сравнение          |
| `styles.css` | стили, включая тёмную тему и печать                                |
| `app.js`     | загрузка данных из Google Sheets, фильтры, таблица, карта, экспорт |

## Возможности

- KPI по годам со сквозным drill-down: клик по карточке или по году на графике открывает
  таблицу с фильтрами по статусу и году.
- Фильтры: ФО, объект, категория, статус, год РВ. Панель столбцов с drag & drop.
- Таблица с закреплённой шапкой и первым столбцом, экспорт выборки в Excel (листы «Сводка»
  и «Выборка»).
- Карта площадок: координаты хранятся в `app.js`, ключ Яндекса — только локально; дневной
  лимит загрузок карты учитывается в `localStorage`.
- Сравнение двух файлов `.xlsx` с подсветкой добавленных, изменённых и удалённых строк.

## Ветвление

`main` — всегда рабочая версия. Работа ведётся в отдельных ветках:

```powershell
git switch main
git pull
git switch -c feature/<задача>
# правки...
git commit -m "feat: ..."
git push -u origin feature/<задача>
```

Затем Pull Request в `main`.

## Данные

Источник — публичная Google-таблица (gviz). Параметры в начале `app.js`:

```js
const CONFIG = {
  sheetId: "...",
  sheetName: "data",
  cacheTtlMs: 10 * 60 * 1000,
  autoRefreshMs: 5 * 60 * 1000,
};
```

## Карта

Ключ Яндекс.Карт (сервис «JavaScript API») не хранится в репозитории. На вкладке «Карта»
вставьте его в поле «Ключ JavaScript API» — он сохранится в браузере. Альтернатива:
`?mapsKey=ВАШ_КЛЮЧ` в адресе страницы.

В кабинете Яндекса у ключа должны быть разрешены домены, с которых открывается дашборд:
`localhost`, `ka2106.github.io` и ваш боевой домен. Без `localhost` локально карта вернёт
`Invalid API key`.
