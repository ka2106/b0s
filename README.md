# БОС · Аналитика

Одностраничный дашборд строительства складов: сводные KPI, реестр объектов, карта площадок
и сравнение двух выгрузок. Без сборки и зависимостей — только статические файлы.

## Быстрый старт

```powershell
git clone https://github.com/ka2106/b0s.git
cd b0s
npx serve -l 5173 .
```

Открыть <http://localhost:5173>. Ключ Яндекс.Карт уже лежит в [`config.js`](config.js) — вводить
ничего не нужно, карта работает сразу (публичный ключ, ограничен по HTTP Referer).

Подробная инструкция для нового устройства (с нуля: Git, Node.js, VS Code, доступ к GitHub):
[`docs/setup-new-device.html`](docs/setup-new-device.html) — открывается двойным кликом в браузере.

## Состав

| Файл         | Назначение                                                         |
| ------------ | ------------------------------------------------------------------ |
| `index.html` | разметка всех вкладок: Дашборд, Таблица, Карта, Сравнение          |
| `styles.css` | стили, включая тёмную тему и печать                                |
| `app.js`     | загрузка данных из Google Sheets, фильтры, таблица, карта, экспорт |
| `config.js`  | ключ Яндекс.Карт (публичный, ограничен по домену)                  |

## Возможности

- KPI по годам со сквозным drill-down: клик по карточке или по году на графике открывает
  таблицу с фильтрами по статусу и году.
- Фильтры: ФО, объект, категория, статус, год РВ. Панель столбцов с drag & drop.
- Таблица с закреплённой шапкой и первым столбцом, экспорт выборки в Excel (листы «Сводка»
  и «Выборка»).
- Карта площадок: координаты хранятся в `app.js`, ключ Яндекса — в `config.js`; дневной
  лимит загрузок карты (100) считается локально в `localStorage`.
- Диагностика: страница с `?debug=1` показывает fps, худший кадр, длинные задачи, тайлы, heap,
  размер canvas и число маркеров — удобно при жалобах на тормоза.
- Сравнение двух файлов `.xlsx` с подсветкой добавленных, изменённых и удалённых строк.

## Ветвление

`main` — всегда рабочая версия. Работа ведётся в отдельных ветках:

```powershell
git switch main
git pull
git switch -c feature/<задача>
# правки...
git commit -m "feat: ..."
git push -u origin feature/<задача>
```

Затем Pull Request в `main`.

## Данные

Источник — публичная Google-таблица (gviz). Параметры в начале `app.js`:

```js
const CONFIG = {
  sheetId: "...",
  sheetName: "data",
  cacheTtlMs: 10 * 60 * 1000,
  autoRefreshMs: 5 * 60 * 1000,
};
```

## Карта

Ключ Яндекс.Карт (продукт «JavaScript API») лежит в [`config.js`](config.js) и работает у всех
посетителей без ввода. Ключ публичный — его защита в том, что в кабинете Яндекса он ограничен
по HTTP Referer:

```
ka2106.github.io
paragulgov.ru
localhost
127.0.0.1
```

Первые два — боевые адреса, вторые два нужны для локальной разработки. Если открыть дашборд как
файл (`file://`), Referer не отправляется и Яндекс отклонит ключ — используйте
`http://localhost:5173`. При ротации ключа правится одна строка в `config.js`.
